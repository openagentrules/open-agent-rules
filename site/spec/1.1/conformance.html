Conformance

Run the corpus against your implementation

Fetch the index, fetch each fixture it names, and run each one: load the rule, apply the input, and compare against expected. An implementation claiming conformance passes every fixture whose clauses fall inside the profiles it declares, and reports the ones it skipped.

curl https://openagentrules.org/spec/1.1/conformance/manifest.json

The runner algorithm

The requirements below define the evaluation algorithm end to end. Each step is separately identified so a conformance fixture can cite it.

  • [OAR-CONF-1] Load each rule document and validate it against the published OAR schema. An engine MUST reject a document that fails validation, naming the failing field.
  • [OAR-CONF-2] An engine MUST reject a document whose spec_version major is unsupported, before any other processing of that document.
  • [OAR-CONF-3] An engine MUST resolve on: a core anchor identifier through the anchor profile map, any other value as a host-native anchor identifier.
  • [OAR-CONF-4] An engine MUST reject a rule whose requires_facts are not all provided by the host.
  • [OAR-CONF-5] An engine MUST type-check when against the declared fact environment and MUST reject the rule on an unknown identifier or a type error.
  • [OAR-CONF-6] At an anchor occurrence, an engine MUST select the rules whose resolved on matches and whose selector clauses all match.
  • [OAR-CONF-7] An engine MUST assemble the facts the selected rules reference. A fact provider failure MUST be handled per the rule's on_error.
  • [OAR-CONF-8] An engine MUST evaluate when. A rule with neither when nor flow fires whenever it is selected.
  • [OAR-CONF-9] An engine MUST record but not act on a rule whose enforcement is monitor: no effect, no side-effect, no short-circuit.
  • [OAR-CONF-10] An engine MUST order evaluation by kind then id, and the first enforced rule firing with block or transform MUST short-circuit the occurrence.
  • [OAR-CONF-11] An engine MUST apply decision precedence: block, then nudge, then warn, otherwise allow.
  • [OAR-CONF-12] An engine MUST apply the on_fire actions of every rule that fired and was enforced.
